---
title: User Satisfaction
description: Analyzes the vocal and emotional journey of the user throughout the conversation, the service quality given by the AI along with the overall value delivered to the user
---

## Input
- **Required Inputs:**
  - **`actual_output`**: URL of the audio recording to evaluate

## Output
- **`Result`**: Score is one among the discrete values : 0.2, 0.4, 0.6, 0.8, 1
- **`Reasoning`**: Brief explanation for the score

## Interpretation
- **0.2**: Very dissatisfied
- **0.4**: Dissatisfied
- **0.6**: Neutral
- **0.8**: Satisfied
- **1.0**: Very satisfied
