## Why curate datasets from logs?

Production logs represent real-world interactions with your AI application. Creating datasets from these logs allows you to:

- **Evaluate on real data** instead of synthetic test cases
- **Focus on problem areas** by filtering for errors or low-quality responses
- **Build regression test sets** from known good or bad examples
- **Track quality over time** by creating datasets from different time periods

## Curating via the Dashboard

The easiest way to create a dataset from logs is through the Maxim dashboard.

<Steps>
<Step title="Navigate to your Log Repository">
Go to the Log Repository containing the logs you want to evaluate.
</Step>

<Step title="Filter the logs">
Use the filter bar to narrow down logs based on:
- **Time range** - Select a specific date/time window
- **Tags** - Filter by custom tags like `user_id`, `model_version`, etc.
- **Metrics** - Filter by latency, cost, or token usage
- **Errors** - Show only logs with errors
- **Evaluator scores** - Filter by existing evaluation results (if using online evals)
</Step>

<Step title="Select logs to add">
Use the checkbox to select individual logs, or click the top-left selector to select all filtered logs.
</Step>

<Step title="Add to dataset">
Click **Add to Dataset** and choose to:
- Create a new dataset, or
- Add to an existing dataset
</Step>

<Step title="Map columns">
Map the log fields to dataset columns:
- `trace.input` → `INPUT`
- `trace.output` → `OUTPUT`
- `generation.retrieved_context` → `CONTEXT`
- Custom fields → `VARIABLE`

Click **Add entries** to complete.
</Step>
</Steps>

## Curating via the SDK

For programmatic control, you can export logs and create datasets using the SDK.

### Export Logs via API

<CodeGroup>
```python Python
from maxim import Maxim

maxim = Maxim({"api_key": "your-api-key"})

# Search logs from a repository
logs = maxim.logs.search(
    repository_id="your-log-repository-id",
    workspace_id="your-workspace-id",
    query={
        "start_time": "2024-01-01T00:00:00Z",
        "end_time": "2024-01-31T23:59:59Z",
        "tags": {"model_version": "v2"},
    },
    limit=100,
)

# Transform to dataset format
dataset_entries = []
for log in logs:
    dataset_entries.append({
        "input": log.input,
        "output": log.output,
        "context": log.get("retrieved_context", ""),
    })
```

```typescript JS/TS
import { Maxim } from '@maximai/maxim-js';

const maxim = new Maxim({ apiKey: 'your-api-key' });

// Search logs from a repository
const logs = await maxim.logs.search({
  repositoryId: 'your-log-repository-id',
  workspaceId: 'your-workspace-id',
  query: {
    startTime: '2024-01-01T00:00:00Z',
    endTime: '2024-01-31T23:59:59Z',
    tags: { modelVersion: 'v2' },
  },
  limit: 100,
});

// Transform to dataset format
const datasetEntries = logs.map((log) => ({
  input: log.input,
  output: log.output,
  context: log.retrievedContext || '',
}));
```
</CodeGroup>

### Create a Dataset

Once you have the log data, create a dataset on the platform:

<CodeGroup>
```python Python
# Create dataset on Maxim
dataset = maxim.datasets.create(
    workspace_id="your-workspace-id",
    name="Production Logs - January 2024",
    description="Curated from production logs for quality analysis",
)

# Add entries
maxim.datasets.add_entries(
    dataset_id=dataset.id,
    entries=dataset_entries,
)

print(f"Created dataset: {dataset.id}")
```

```typescript JS/TS
// Create dataset on Maxim
const dataset = await maxim.datasets.create({
  workspaceId: 'your-workspace-id',
  name: 'Production Logs - January 2024',
  description: 'Curated from production logs for quality analysis',
});

// Add entries
await maxim.datasets.addEntries({
  datasetId: dataset.id,
  entries: datasetEntries,
});

console.log(`Created dataset: ${dataset.id}`);
```
</CodeGroup>

## Using a Local Dataset

Alternatively, use the log data directly as a local dataset without uploading to the platform:

<CodeGroup>
```python Python
from maxim.models import LocalData, YieldedOutput

# Use logs directly as local dataset
local_dataset: list[LocalData] = [
    {"input": log["input"], "output": log["output"]}
    for log in exported_logs
]

def replay_output(data: LocalData) -> YieldedOutput:
    return YieldedOutput(data=data.get("Output") or data.get("output") or "")

result = (
    maxim.create_test_run(
        name="Local Dataset Eval",
        in_workspace_id="your-workspace-id"
    )
    .with_data(local_dataset)
    .with_data_structure({"input": "INPUT", "output": "OUTPUT"})
    .yields_output(replay_output)
    .with_evaluators("Clarity")
    .run()
)
```

```typescript JS/TS
import { type Data, type YieldedOutput } from '@maximai/maxim-js';

// Use logs directly as local dataset
const localDataset: Data[] = exportedLogs.map((log) => ({
  input: log.input,
  output: log.output,
}));

function replayOutput(data: Data): YieldedOutput {
  return { data: data.output || '' };
}

const result = await maxim
  .createTestRun('Local Dataset Eval', 'your-workspace-id')
  .withData(localDataset)
  .withDataStructure({ input: 'INPUT', output: 'OUTPUT' })
  .yieldsOutput(replayOutput)
  .withEvaluators('Clarity')
  .run();
```
</CodeGroup>

## Best Practices

1. **Use meaningful filters** - Don't just grab random logs; filter for specific scenarios you want to analyze
2. **Include metadata** - Preserve tags, timestamps, and other metadata that might be useful for analysis
3. **Balance your dataset** - Include a mix of successful and problematic interactions
4. **Document your datasets** - Use clear names and descriptions so team members understand what each dataset contains
5. **Regular curation** - Set up periodic dataset creation to track quality trends over time
