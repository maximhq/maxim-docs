## How to use variables in your no-code agent?
Use variables to pass data to your agent directly from your Dataset.

<Steps>
<Step title="Create a dataset with custom variables">

Create custom columns of the type `Variable` in your dataset. All data from these columns would be available as variables in your agent.
![Dataset with custom variables](/images/docs/evaluate/how-to/prompt-chains/agents-variables-dataset.png)

</Step>
<Step title="Use variables in your agent">

Use the variables in any of your nodes using the `{{variable_name}}` syntax.
![Variables in agent](/images/docs/evaluate/how-to/prompt-chains/agents-multilingual-variables.png)

</Step>
<Step title="Test your agent">

Trigger a test run and view the results.
![Agent in playground](/images/docs/evaluate/how-to/prompt-chains/agents-variables-test-run-report.png)

</Step>
</Steps>

<Warning>
Any value set in the agent while testing would be overridden by the value from the dataset.
</Warning>
