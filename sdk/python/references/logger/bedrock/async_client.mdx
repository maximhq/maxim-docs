## [MaximBedrockAsyncClient](/sdk/python/references/logger/bedrock/async_client)

```python
class MaximBedrockAsyncClient()
```

[Maxim](/sdk/python/references/maxim) Bedrock async client wrapper.

This class provides a wrapper around the Bedrock async client to integrate
with [Maxim](/sdk/python/references/maxim)'s logging and monitoring capabilities. It allows tracking
and logging of Bedrock API interactions through the [Maxim](/sdk/python/references/maxim) platform.
