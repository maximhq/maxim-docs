#### is\_silence

```python
def is_silence(pcm_bytes, threshold=500, min_silence_ratio=0.95)
```

Detects if the given PCM16 byte buffer is mostly silence.

**Arguments**:

| Name | Type | Description |
|------|------|-------------|
| `pcm_bytes` | _bytes_ | PCM16LE audio data. |
| `threshold` | _int_ | Max absolute value to consider as silence. |
| `min_silence_ratio` | _float_ | Minimum ratio of silent samples to consider the buffer as silence. |

**Returns**:

| Name | Description |
|------|-------------|
| `bool` | True if buffer is mostly silence, False otherwise. |

#### pcm16\_to\_wav\_bytes

```python
def pcm16_to_wav_bytes(pcm_bytes: bytes,
                       num_channels: int = 1,
                       sample_rate: int = 24000) -> bytes
```

Convert PCM-16 audio data to WAV format bytes.

**Arguments**:

| Name | Type | Description |
|------|------|-------------|
| `pcm_bytes` | _bytes_ | Raw PCM-16 audio data |
| `num_channels` | _int_ | Number of audio channels (default: 1) |
| `sample_rate` | _int_ | Sample rate in Hz (default: 24000) |

**Returns**:

| Name | Description |
|------|-------------|
| `bytes` | WAV format audio data |
