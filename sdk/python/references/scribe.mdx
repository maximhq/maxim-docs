## [Scribe](/sdk/python/references/scribe)

[View source on GitHub](https://github.com/maximhq/maxim-py/blob/main/maxim/scribe.py#L10)


```python
class Scribe()
```

[Scribe](/sdk/python/references/scribe) logger wrapper for maxim.
Log level is managed externally via set_level or the standard logging API.
By default, the logger uses the global logging configuration.
