## Env variables

```
MAXIM_API_KEY=
MAXIM_LOG_REPO_ID=
MISTRAL_API_KEY=
```

## Initialize logger

```python
from maxim import Maxim

logger = Maxim().logger()
```

## Initialize MaximMistralClient

```python {5,7}
from mistralai import Mistral
from maxim.logger.mistral import MaximMistralClient
import os

with MaximMistralClient(Mistral(
    api_key=os.getenv("MISTRAL_API_KEY", ""),
), logger) as mistral:
    # Your Mistral calls go here
    pass
```

## Make LLM calls using MaximMistralClient

```python
from mistralai import Mistral
from maxim.logger.mistral import MaximMistralClient
import os

with MaximMistralClient(Mistral(
    api_key=os.getenv("MISTRAL_API_KEY", ""),
), logger) as mistral:

    res = mistral.chat.complete(
        model="mistral-small-latest", 
        messages=[
            {
                "content": "Who is the best French painter? Answer in one short sentence.",
                "role": "user",
            },
        ]
    )

    # Handle response
    print(res)
```

## Async LLM calls

```python
async with MaximMistralClient(Mistral(
    api_key=os.getenv('MISTRAL_API_KEY', ''),
), logger) as mistral:
    
    response = await mistral.chat.complete_async(
        model='mistral-small-latest',
        messages=[
            {
                'role': 'user',
                'content': 'Explain the difference between async and sync programming in Python in one sentence.'
            }
        ]
    )    
    print(response)
```

## Advanced use-cases

### Capture multiple LLM calls in one trace

#### Step 1: Initialize Maxim SDK and Mistral Client

```python
from mistralai import Mistral
from maxim import Maxim
from maxim.logger.mistral import MaximMistralClient
import os

# Make sure MAXIM_API_KEY and MAXIM_LOG_REPO_ID are set in env variables
logger = Maxim().logger()

# Initialize MaximMistralClient
mistral_client = Mistral(api_key=os.getenv("MISTRAL_API_KEY", ""))
```

#### Step 2: Create a new trace externally

```python
from uuid import uuid4

trace_id = str(uuid4())

trace = logger.trace({
    "id": trace_id,
    "name": "Trace name"
})
```

#### Step 3: Make LLM calls and use this trace id

```python
with MaximMistralClient(mistral_client, logger) as mistral:
    res = mistral.chat.complete(
        model="mistral-small-latest",
        messages=[
            {
                "content": "What is machine learning?",
                "role": "user",
            },
        ],
        extra_headers={"x-maxim-trace-id": trace_id}
    )
    print(res)
```

#### Step 4: Keep adding LLM calls

All LLM calls with extra header `x-maxim-trace-id: trace_id` will add it to the declared trace.

### Capture multi-turn conversations

#### Step 1: Initialize Maxim SDK and Mistral Client

```python
from mistralai import Mistral
from maxim import Maxim
from maxim.logger.mistral import MaximMistralClient
import os

# Make sure MAXIM_API_KEY and MAXIM_LOG_REPO_ID are set in env variables
logger = Maxim().logger()

# Initialize MaximMistralClient
mistral_client = Mistral(api_key=os.getenv("MISTRAL_API_KEY", ""))
```

#### Step 2: Create a new trace externally and add it to a session

```python
from uuid import uuid4

# use this session id to add multiple traces in one session
session_id = str(uuid4())

trace_id = str(uuid4())

trace = logger.trace({
    "id": trace_id,
    "name": "Trace name",
    "session_id": session_id
})
```

#### Step 3: Make LLM calls and use this trace id

```python
with MaximMistralClient(mistral_client, logger) as mistral:
    res = mistral.chat.complete(
        model="mistral-small-latest",
        messages=[
            {
                "content": "Tell me about Paris.",
                "role": "user",
            },
        ],
        extra_headers={"x-maxim-trace-id": trace_id}
    )
    print(res)
```

#### Step 4: Continue the conversation in the same session

```python
# Create another trace for the follow-up question
trace_id_2 = str(uuid4())

trace_2 = logger.trace({
    "id": trace_id_2,
    "name": "Follow-up question",
    "session_id": session_id  # Same session ID
})

with MaximMistralClient(mistral_client, logger) as mistral:
    res = mistral.chat.complete(
        model="mistral-small-latest",
        messages=[
            {
                "content": "What's the best time to visit?",
                "role": "user",
            },
        ],
        extra_headers={"x-maxim-trace-id": trace_id_2}
    )
    print(res)
```

## Supported Mistral Models

The MaximMistralClient supports all Mistral models available through the Mistral API, including:

- `mistral-small-latest`
- `mistral-medium-latest`
- `mistral-large-latest`
- `open-mistral-7b`
- `open-mistral-8x7b`
- `open-mistral-8x22b`
- And other available Mistral models
