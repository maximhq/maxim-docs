title: "One-line integration with OpenAI Realtime and ElevenLabs"
description: "22 November 2025"

Maxim now supports a single-line integration to log and trace voice agents built using OpenAI Realtime and ElevenLabs.

With just one line of code, you can use [<u>Maxim’s observability suite</u>](https://www.getmaxim.ai/products/agent-observability) to capture agent interactions, run continuous evaluations on recordings and transcripts, gain detailed insights into conversation flows and performance metrics, and continuously improve your voice agents.
